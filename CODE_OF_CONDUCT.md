# Helm Community Code of Conduct

Helm is built for curious, collaborative developers. We want people to be able to ask questions, propose changes, and disagree constructively.

## Our standards

- Be respectful, welcoming, and considerate of different skill levels and backgrounds.
- Discuss technical claims with evidence, and assume good intent while keeping boundaries.
- Give actionable feedback and credit contributors for their work.
- Protect personal information and respect the time of volunteers.
- Disagree with ideas, not people.

Harassment, threats, hateful language, discrimination, targeted insults, doxxing, sexual harassment, and sustained disruption are not acceptable.

## Scope

These expectations apply to Helm issues, pull requests, code reviews, discussions, and other project spaces.

## Reporting and enforcement

If you encounter unacceptable behavior, contact the repository maintainer privately through GitHub. Do not post private details or personal identifiers publicly. The maintainer may ask participants to revise content, close discussions, remove contributions, limit participation, or report abusive behavior to GitHub.

Project decisions should be made on technical merit, user impact, and safety; disagreement alone is not a violation.

This project policy may be revised as the community grows.
