# Helm v0.4.0 — Initial public release

[Official GitHub Release](https://github.com/samjuniors/Helm/releases/tag/v0.4.0)

This historical record summarizes the release notes published for v0.4.0; it is not a new test certification.

## Shipped

- Project initialization, roadmap steps, milestones, checkpoints, and recovery.
- Git-aware project execution and QA workflows.
- Optional specialist roles for research, testing, debugging, and review.
- MCP server integration for supported coding clients.
- Release packaging and installation/upgrade instructions.

## Safety and compatibility

The release includes Git safety fixes intended to preserve pre-existing user work and avoids replacing project state without a migration. External agents still run with the host user's permissions; a Git worktree does not sandbox execution.

## Requirements and downloads

Node.js 18+, Git, and an MCP-capable client for integrated use. The official release provides `helm-v0.4.0.zip`, `helm-v0.4.0.tgz`, and `SHA256SUMS`.

## Verification status at publication

The original GitHub release notes reported passing local tests while full GitHub Actions verification remained pending. This is historical evidence only; do not infer green cross-platform CI for this version.

For a new install use the [current installation guide](../INSTALLATION.md). To upgrade an existing v0.4.0 package, use the matching legacy method in [Upgrading](../UPGRADING.md).
