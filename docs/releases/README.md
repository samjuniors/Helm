# Helm versioned release notes

[Latest GitHub Release](https://github.com/samjuniors/Helm/releases/latest) · [Changelog](../../CHANGELOG.md) · [Installation](../INSTALLATION.md) · [Upgrading](../UPGRADING.md)

Each release is identified by a Git tag and has an official GitHub Releases page with downloadable ZIP and TGZ archives plus SHA-256 checksums. These notes summarize the version-specific changes and limitations. **Do not infer test results from a version number.**

**v0.5.0 was not published as a separate release.** Its work was incorporated into v0.6.0.

Helm uses Semantic Versioning: PATCH for fixes, MINOR for additions and pre-1.0 breaking changes, and MAJOR for stable/post-1.0 breaking milestones. See [release procedure](../RELEASING.md) for maintainer instructions.
