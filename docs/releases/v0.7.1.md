# Helm v0.7.1 — Cross-platform CI and setup hardening

**Version:** 0.7.1 (patch update from v0.7.0).
**Requirements:** Node.js 18+, Git, MCP stdio client for integration.

## Fixes

- Read NUL-delimited Git changed-file paths and normalize separators for helper role-scope checks. Exact tester reports are permitted; unrelated application-source edits remain blocked.
- Align Unix setup regression assertions with actual successful self-test, safe downgrade refusal and cleanup.
- Remove an empty Helm configuration directory after an explicit purging uninstall, while preserving unrelated files and projects.
- Enforce custom, version-specific release notes in the package metadata check.

## Compatibility and security

No changes to existing project roadmaps, the `.agents/product-kit/` directory layout or the MCP tool names (14 tools). Existing Git work, source checkouts and client registrations are preserved. Helper agents execute with host-user permissions; Git worktrees are not a security sandbox.

## Upgrade

Download and verify the new `helm-v0.7.1.zip` and `SHA256SUMS` from GitHub Releases. Extract to a separate folder and run:

~~~sh
node setup.mjs update --dry-run
node setup.mjs update
~~~

For an older manually installed ZIP without a setup record, use the new release's `node update.mjs --into OLD-INSTALL --dry-run` followed by the same command without `--dry-run`. Git-clone installations should be updated using Git. Restart MCP clients. Project kit engines do not need an automatic migration.

## Downloads

- `helm-v0.7.1.zip` — versioned installable archive.
- `helm-v0.7.1.tgz` — npm-compatible archive, not published to the npm registry.
- `SHA256SUMS` — SHA-256 checksums for both archives.

## Verification and limitations

Windows/Ubuntu hosted Node 18/22 CI and local integration results are recorded on the release PR and linked GitHub Actions runs. Do not treat a failed or unexecuted matrix job as passing. Actual third-party coding-assistant GUI integrations and macOS real-host behavior are not independently covered by this release.
