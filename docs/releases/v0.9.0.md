# Helm v0.9.0 — One-Command Installation and Uninstallation

**Version:** 0.9.0 (MINOR, feature update from v0.8.0)
**Requirements:** Node.js 18+, Git for managed project workflows. macOS/Linux bootstrap also uses curl and tar.

## What's new

The Helm command line now supports:

```sh
helm install --dry-run
helm install
helm uninstall --dry-run
helm uninstall
helm update
```

- **Install:** creates a managed Helm copy in the standard user folder and registers supported MCP clients where available. An existing managed installation is left unchanged.
- **Uninstall:** previews and confirms removal of the recorded managed copy, owned launcher and selected MCP registrations. User projects, Git history and unrelated files are not removed. A non-interactive caller must explicitly pass `--yes`.
- **First-time bootstrap without a clone or browser ZIP:** Windows PowerShell and Unix scripts fetch an official stable GitHub Release, verify SHA-256, check the archive contents and invoke Helm's existing guarded installer. Downloads and extraction occur under a temporary directory, not within user project directories.
- **Update:** `helm update` (introduced in v0.8.0) remains the verified upgrade path for setup-managed installs.

## Get started

For Windows, review the tagged [bootstrap PowerShell script](https://github.com/samjuniors/Helm/blob/v0.9.0/scripts/bootstrap.ps1) and use the version-pinned command from the [installation guide](https://github.com/samjuniors/Helm/blob/main/docs/INSTALLATION.md).

For Linux/macOS, review the tagged [bootstrap shell script](https://github.com/samjuniors/Helm/blob/v0.9.0/scripts/bootstrap.sh) and follow the same installation guide.

Existing users with a managed v0.8.0 installation can update using `helm update`. Source Git checkouts remain Git-managed; no automatic overwrites.

## Security and compatibility

This release preserves Helm's package identity, MIT license, all 14 MCP tools, and the existing `.agents/product-kit/` project state. Bootstrap checks the published ZIP/TGZ against SHA256SUMS before running setup. Existing per-project files and Git history are never deleted by the uninstaller. Git source clones are retained and must be removed manually if deliberately desired.

Do not execute remote scripts you have not reviewed. The scripts are source-visible and pinned to this release tag; inspecting and executing locally is the safer alternative to piping directly to a shell.

## Assets

- `helm-v0.9.0.zip` — installable release
- `helm-v0.9.0.tgz` — npm-compatible distribution (not published on npm)
- `SHA256SUMS` — SHA-256 hashes

## Testing and limitations

The release PR's local and hosted CI records contain executed tests. In particular, isolated installs/uninstalls must be tested on Windows and Unix without touching real host registrations. GUI integrations with third-party coding assistants are not equivalent to running the automated CLI tests and should be verified separately.
